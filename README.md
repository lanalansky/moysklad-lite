# MoySkladLite

Лёгкий аналог МойСклад для личного/малого бизнеса: товары и остатки, контрагенты, заказы.

- **Фронтенд** — статичный сайт (HTML/CSS/JS), хостится бесплатно на GitHub Pages.
- **База данных** — обычная Google Таблица.
- **API** — Google Apps Script, привязанный к таблице (тоже бесплатно, часть вашего Google-аккаунта).

Работает полностью на ваших собственных GitHub и Google аккаунтах — без серверов и без подписок.

## Настройка (займёт 10-15 минут)

### 1. Создайте Google Таблицу

1. Откройте [sheets.google.com](https://sheets.google.com) → создайте новую пустую таблицу.
2. Назовите её, например, "MoySkladLite Data".
3. Листы `Products`, `Contacts`, `Orders` создадутся автоматически при первом запросе — вручную ничего создавать не нужно.

### 2. Подключите Apps Script

1. В таблице: **Расширения → Apps Script**.
2. Удалите содержимое файла `Code.gs` по умолчанию и вставьте туда содержимое файла [`apps-script/Code.gs`](apps-script/Code.gs) из этого проекта.
3. Сохраните проект (значок дискеты), дайте ему имя, например "MoySkladLite API".

### 3. Разверните как веб-приложение

1. Нажмите **Развернуть → Новое развёртывание**.
2. Тип: **Веб-приложение**.
3. Настройки:
   - **Выполнять как:** Я (ваш аккаунт)
   - **У кого есть доступ:** Все (Anyone)
4. Нажмите **Развернуть**, разрешите доступ (потребуется подтвердить, что вы доверяете своему же скрипту).
5. Скопируйте появившийся **URL веб-приложения** (заканчивается на `/exec`).

### 4. Укажите URL в проекте

Откройте [`config.js`](config.js) и вставьте скопированный URL:

```js
const CONFIG = {
  API_URL: "https://script.google.com/macros/s/ВАШ_ID/exec"
};
```

### 5. Проверьте локально

Откройте `index.html` в браузере напрямую (двойной клик) или через локальный сервер — данные должны подтянуться из таблицы (изначально пусто).

### 6. Опубликуйте на GitHub Pages

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/moysklad-lite.git
git push -u origin main
```

Затем в настройках репозитория на GitHub: **Settings → Pages → Source: main branch, / (root)**. Через пару минут сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/moysklad-lite/`.

## Важно про повторное развёртывание

Если вы меняете `apps-script/Code.gs`, изменения нужно вручную скопировать в редактор Apps Script и создать **новую версию** развёртывания (Развернуть → Управление развёртываниями → редактировать → New version), иначе изменения не применятся.

## Важно про кэш браузера

`index.html` подключает `app.js`, `style.css` и `config.js` с версией в ссылке (`app.js?v=2`). Браузеры и GitHub Pages держат эти файлы в кэше до 10 минут — без версии в ссылке после каждого обновления сайта могла бы показываться смесь старого JS с новым HTML. При каждом изменении `app.js`, `style.css` или `config.js` увеличивайте `?v=N` на 1 во всех трёх местах в `index.html`, иначе часть посетителей будет видеть устаревшую версию до 10 минут после публикации.

## Структура данных

- **Products**: ID, Name, SKU, Unit, Price, Quantity, Category
- **Contacts**: ID, Name, Type (client/supplier), Phone, Email, Address
- **Orders**: ID, Date, ContactID, ContactName, Type (sale/purchase), Status, ItemsJSON, Total

Данные всегда можно посмотреть и поправить прямо в Google Таблице — интерфейс лишь читает и пишет в неё через API.

## Возможные доработки

- Печатные формы (накладные, счета)
- Отдельные листы для позиций заказов вместо JSON-колонки
- Фильтры и поиск по таблицам
- Многопользовательский доступ с ролями
